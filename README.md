# Lithophany — versions à télécharger

Versions de **Lithophany**, l'app qui transforme vos photos en lithophanies prêtes à imprimer en 3D (Mac).
Développée par [JEREMiA](https://www.jerem-ia.fr).

- Présentation, prix et achat de la licence Pro : https://www.jerem-ia.fr/lithophany
- La version gratuite fonctionne sans licence (lithophanie plate monochrome, avec pied ou boîte lumineuse).
- Support : contact@jerem-ia.fr

Ce dépôt ne contient que les binaires publiés (onglet **Releases**) ; le code source de l'app n'est pas public.
